Rx Box: Smart Medication Reminder & Dispenser System

IoT Hardware ESP32 Rotating Carousel Drop Sensors Audio & LED Alarms Web Dashboard

A smart pillbox designed to help patients take their prescribed medication on time. It uses an automated rotating carousel to dispense medicine at scheduled hours, sounds alert alarms with flashing lights, and verifies pill retrieval with internal sensors.

My Key Role Project Manager
Output & Result 100% Reliable Dispensing
View Objectives & Technical Specifications
Project Objectives
  • Automatically dispense pills at scheduled times using a motorized rotating carousel.
  • Verify that medicine is actually taken using built-in sensors when the pill drops and drawer opens.
  • Provide easy-to-notice sound alarms and LED lights to help elderly patients or those with vision/hearing difficulty.
  • Send real-time updates and missed-dose notifications to a companion web dashboard for family members and caregivers.

A smart trash bin system designed to promote clean and touchless waste disposal in school facilities. It uses distance sensors to monitor bin capacity in real time and automated motorized lids for hands-free opening, helping separate waste cleanly.

My Key Role Project Manager
Output & Result Defended 3-Bin Prototype
View Objectives & Technical Specifications
Project Objectives
  • Provide hands-free, touchless waste disposal through automated motor lids to improve hygiene.
  • Monitor how full each bin compartment is in real time using ultrasonic distance sensors.
  • Prevent bin overflow and unpleasant odors by alerting maintenance when a compartment is nearly full.
  • Provide a working demonstration prototype for automated waste sorting on campus.
